This directory is a safe Data Package v4 campaign template.

Selecting example.campaign uses the normal JA2 campaign bootstrap and installed
legacy data beneath this package's read-only overlay. Copy the directory, give
the package a unique ID, and add maps, XML, artwork, sound, localization, and
definition assets below Data/ using their normal logical paths.

The template targets CAMPAIGN_FAMILY=ja2. An Unfinished Business campaign must
use CAMPAIGN_FAMILY=unfinished-business and run with the UB executable.
